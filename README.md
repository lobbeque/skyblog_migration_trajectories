# Datascape and Scripts for Visualising and Studying Digital Migrations

All code components are related to the article "_Digital Migrations and the Making of Online Identity: Historical Evidence from Skyblog Archives_" authored by Quentin Lobbé.

**contact:** quentin.lobbe@gmail.com

### Datascape

A companion interface designed to visualise 257 migration trajectories. Simply download all the files and open `index.html` in a web browser.

### Scripts 

Open the folder `/scripts/`

* `skyblogsUtils.py` : a set of functions to easily explore Skyblog archives
* `findClosures.py` : detects potential closure messages in the archives
* `fansToEgoNetworks.py` : change a list of fans and fans of fans into ego networks
* `measureEgoNetworks.py` : compute a set of metrics from ego networks
* `metricsToPCA`.py : compute a PCA from a collection of ego networks' metrics
